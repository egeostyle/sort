Configuración de Firebase Firestore

Firebase es el servicio gratuito de Google que sincroniza los boletos en tiempo real en la nube sin requerir servidores encendidos.

Para obtener estas claves gratis: Entra a console.firebase.google.com → Crea un proyecto → Activa Cloud Firestore → Agrega una app web.
